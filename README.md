# Gay Fornication GUI

A custom GUI for Roblox, designed to enhance the user experience with a sleek and intuitive interface.

## Features

- **Customizable Layout:** Users can rearrange and resize GUI elements to suit their preferences.
- **Themed Design:** Choose from a variety of themes to personalize the look and feel.
- **Interactive Elements:** Buttons, sliders, and input fields with smooth animations and feedback.
- **Error Handling:** Robust error handling to ensure a stable and reliable user experience.

## Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/yourusername/gay-fornication-gui.git
   cd gay-fornication-gui
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Run the Application:**
   ```bash
   npm start
   ```

## Usage

### Customizing the GUI

1. **Open the Configuration File:**
   ```bash
   nano config.json
   ```

2. **Modify Settings:**
   Adjust the layout, themes, and other settings as needed.

### Handling Errors

The application includes comprehensive error handling to manage unexpected issues gracefully. Errors are logged to `error.log` for debugging purposes.
